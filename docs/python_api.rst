Python API
==========

The Python helpers expose utilities for mesh preparation, IO, and solver orchestration. This section is generated from module docstrings so it stays up to date with the code.

Usage
-----

.. code-block:: python

   from pytec3d import Solver, selection

   with Solver() as solver:
       solver.read_model("mesh.vtu")
       solver.model.read_json("model_data.json")
       selection.select(solver.model.mesh, "MATERIAL", 2, location="elem")
       selection.nsle(solver.model.mesh)
       selection.set_value_on_selection(solver.model.mesh, "CP_0", 1)
       solver.load_model_into_solver()
       solver.solve()
       solver.write_output()

Errors derive from :class:`pytec3d.PyTEC3DError` (and from the matching built-in exception): an invalid model raises
:class:`pytec3d.ValidationError` listing every problem, a missing array :class:`pytec3d.MissingArrayError`, a change
to a model loaded into a solver session :class:`pytec3d.ModelLockedError`. The log level is set with
``pytec3d.set_log_level("DEBUG")`` or the environment variable ``PYTEC3D_LOG_LEVEL``.
